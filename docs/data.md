# 数据与现有口径

weight 表示会话路径频次，minute 是会话内分钟。

`data/records.json` 是版本为 1 的演练数据，所有人员、机构、商品和交易均为本地合成记录。`id` 是导入记录键，不自动代表企业、访问或其他统计单位；记录键不得重复。数值字段必须有限，整数字段不得超过安全整数范围。空字符串可用于字段约定允许的未公开标签，不用零冒充缺测。

| 字段 | 类型 |
| --- | --- |
| `id` | `string` |
| `user` | `string` |
| `session` | `string` |
| `minute` | `integer` |
| `channel` | `string` |
| `converted` | `boolean` |
| `weight` | `number` |

现有 `summary` 按 `channel` 清点记录，`sum` 为 `weight` 的逐行核对值，不代表统计推断或跨期业务指标。分组按键排序，行按记录键稳定处理。`data/expected-summary.json` 是独立生成的现有核算对照；`data/policy.json` 保存业务配置的演练值，当前清点命令不消费分析配置。

`inspect` 返回输入行数、字段列表与 SHA-256 指纹；指纹不依赖字段或记录排列。数据版本不支持时应直接拒绝，不做静默迁移。错误发生时命令返回非零退出码。

## Markov 路径归因（attribution）

`attribution` 是与触达核算并列的新口径，**不会改写或替换 `summary` 的结果**。它是描述性路径归因，用于预算讨论，不代表因果投放效果。

### 路径构造

- 以 `user`、`session` 和最大静默间隔（`silenceMinutes`）构造路径：同一 `user` 内按 `(session, minute, id)` 稳定排序；`session` 变化，或同一 `session` 内相邻触点间隔超过静默窗口，都切断为新路径。
- 被静默间隔切断的旧路径以流失（NULL）吸收态收尾，即超时归入未转化终态；转化与未转化路径都进入模型。
- `collapseConsecutive` 为真时折叠连续相同渠道；非连续的同渠道回访始终保留。
- 路径结局由该路径最后一条记录的 `converted` 决定。路径频次取路径内记录的 `weight`（要求同一路径内一致）；相同渠道序列与结局的路径频次相加。频次只在路径层累计一次，绝不按边重复相乘。

### 模型与移除规则

- 一阶 Markov 转移模型包含开始态、转化吸收态、流失吸收态；转移矩阵按行归一化，并求解 `(I-Q)x=r` 得到从开始态出发的总体吸收概率。`I-Q` 不可逆表示存在闭合非吸收子链，此时直接报错，不伪造比例。
- 移除规则固定为 `drop-to-null`：移除某渠道时，该渠道等价于流失吸收态，所有进入该渠道的概率质量（含其自环）全部改道到 NULL；其他状态的概率保持原值，不重新归一化，不跳过触点，也不转嫁给其他渠道或转化态。每条移除结果都记录各来源状态改道到流失的质量。
- 移除效应 = 基线转化吸收概率 − 移除后转化吸收概率。归一化贡献保留负效应符号、不做钳制；效应总和不严格为正（含全部为零，例如只有未转化记录）时 `contributions` 为 `null` 并给出原因代码，不平摊出“合理比例”。

### 稳定区间与窗口对比

- bootstrap 以**整个 user** 为抽样单位（该用户全部路径同时抽中或排除），完整重建路径与模型，不独立抽样边或路径；种子固定时结果可复现，输出贡献与效应的 P5/中位数/P95。
- `silenceWindows` 中的每个静默窗口都重新切分路径并重建模型，档案给出各窗口贡献与按绝对变化降序的渠道排名。

### 配置字段（data/policy.json）

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `silenceMinutes` | 正整数 | 主静默窗口（分钟） |
| `silenceWindows` | 非空正整数数组、不重复 | 窗口对比集合，CLI 可用多个 `--window` 覆盖 |
| `collapseConsecutive` | boolean | 是否折叠连续同渠道 |
| `removal` | 字符串 | 仅支持 `drop-to-null` |
| `bootstrapIterations` | 正整数 | user 整组重抽次数，CLI 可用 `--bootstrap` 覆盖 |
| `seed` | 整数 | 重抽随机种子，CLI 可用 `--seed` 覆盖 |

一次 `attribution` 运行同时产出机器档案（`--out`，JSON，含路径频次、转移计数与矩阵、吸收概率、移除效应、归一贡献、bootstrap、窗口对比及输入/策略指纹）和预算会中文说明（`--report`，Markdown）。
